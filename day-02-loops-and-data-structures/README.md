## What I Learned

During Day 2, I learned how loops can be used to repeatedly process data and control the flow of a program. I practiced using for loops with range() as well as while loops with conditions and break.

I also learned how continue can be used to skip invalid values while processing a list. Another important concept I learned was list and dictionary comprehensions, which allow data to be filtered or transformed in a more concise way.

I also practiced working with sets and set operations to compare datasets, as well as nested dictionaries for representing more structured data. The Contact Book exercise helped me put several of these concepts together in an interactive program.
## CHallenges Faced

The first few exercises were fairly straightforward, but I found some of the later exercises more challenging because they required combining multiple concepts.

The Dataset Comparison exercise required me to understand the different operations that can be performed with sets, while the Student Score Dictionary and Nested Order Summary exercises required me to work more carefully with dictionaries and nested data.

The Stretch Exercise, Contact Book, was probably the most interesting because it required using a while loop, conditional statements, dictionaries, nested dictionaries, and break together to create an interactive program.

I also had to think about error handling when searching for or deleting a contact that does not exist. Overall, this assignment helped me understand how loops and data structures can work together to process and manage data in Python.
